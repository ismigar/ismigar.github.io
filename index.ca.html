El problema que resol Gnosi

La teva recerca és un flux, no una pila d’aplicacions.

Referències en una eina, taules de projecte en una altra, notes en un altre lloc i el text final en una quarta aplicació. La fricció no consisteix a capturar més informació, sinó a preservar el camí que porta de cada afirmació fins a l’evidència.

↔

Feina duplicada

El mateix recurs i les mateixes metadades copiats entre el gestor bibliogràfic, les notes i el projecte.

⌁

Evidències sense context

Els subratllats i les idees acaben deslligats de la pàgina, el paràgraf o la font que els sosté.

□

Coneixement en terreny prestat

Un canvi de preus o polítiques pot deixar anys de feina estructurada sota les regles d’una altra empresa.

La resposta de Gnosi

Una única cadena de custòdia oberta per al coneixement.

Fonts, evidències, notes, enllaços, vistes de projecte i cites es mantenen connectats, mentre que els arxius continuen sent llegibles fora de Gnosi.

El recorregut principal

Un cicle de recerca complet en quatre passos

Comença amb el teu propi material. La IA pot ajudar, però el flux no en depèn.

01

Captura o importa

Afegeix referències amb DOI, ISBN, arXiv, PMID, BibTeX o RIS. Desa pàgines web i obre PDF o EPUB dins de l’espai.

Captura compatible amb Zotero · Web Clipper
02

Llegeix amb evidències

Anota una font i conserva les citacions vinculades a la pàgina, el paràgraf, el capítol o el minut perquè cada afirmació es pugui verificar.

Lector PDF/EPUB · Procedència
03

Connecta i estructura

Converteix les notes de lectura en una síntesi pròpia. Fes servir wikienllaços, el graf, bases de dades, taulers, cronologies i fites.

Markdown · Graf · Vistes de base de dades
04

Escriu i cita

Insereix cites actives de Gnosi a Word o LibreOffice i genera la bibliografia sense duplicar la biblioteca.

CSL/citeproc · Word · LibreOffice
Dissenyat al voltant de la feina

L’estructura de Notion, les connexions d’Obsidian i una capa de recerca nativa

A

Les fonts es converteixen en evidències útils

Gestió de referències, lectors, anotacions, notes de lectura atòmiques i ressaltat exacte comparteixen el mateix context.

B

Les notes també poden ser dades

Les pàgines Markdown incorporen camps tipats, relacions, fórmules, agregacions i vistes de taula, galeria, tauler, calendari o cronologia.

C

La IA continua havent de retre comptes

Utilitza models locals o al núvol per ingerir i cercar material, mantenint visible la procedència i la síntesi permanent sota control humà.

Sobirania des del disseny

El teu espai ha de sobreviure a l’aplicació.

Gnosi fa servir arxius normals com a font de veritat i índexs reconstruïbles per guanyar velocitat. Pots inspeccionar, copiar, versionar i migrar el coneixement sense demanar permís.

  • Markdown + YAMLLlegibles amb un editor de text i compatibles amb eines d’arxius ordinàries.
  • Local-firstL’ús personal no requereix un compte al núvol de Gnosi.

Prova Gnosi

Primer l’aplicació d’escriptori. Allotja-la tu mateix quan ho necessitis.

El camí més ràpid és la versió d’escriptori. Els desplegaments natiu i Docker continuen disponibles per a usuaris tècnics i servidors.

Recomanat
G

Aplicació d’escriptori

El backend ja ve inclòs. La descàrrega detectarà automàticament el teu sistema operatiu (Mac, Windows o Linux).

Descarrega GnosiA macOS: fes clic dret → Obrir la primera vegada. A Linux: activa "Permetre executar com a programa" a Propietats o executa chmod +x fitxer.AppImage.
Per a desenvolupament

Execució nativa

Utilitza Python i Node directament a l’amfitrió. És el flux recomanat per a l’autoallotjament i les contribucions.

git clone git@github.com:ismigar/Gnosi.git
cd Gnosi/apps/gnosi
Consulta la guia d’instal·lació nativa →
Per a servidors

Desplegament amb Docker

Utilitza el desplegament tot en un compatible quan una instal·lació en contenidors encaixi millor al servidor.

docker compose up -d --build
Consulta la guia de Docker →
