Gnosi v1.0.0-rc.2

Prerelease
3 d'agost del 2026
Binaris disponibles a GitHub Releases: macOS (Apple Silicon) .dmg macOS (Intel) .dmg Windows .exe Linux .AppImage Linux .deb

✨ Destacats

  • Les aplicacions d'escriptori ara utilitzen la icona oficial de Gnosi a macOS, Windows i Linux.

🚀 Millores

  • Les compilacions de release verifiquen la signatura de macOS, la icona de l'aplicació i la interfície empaquetada abans de pujar els instal·ladors.

🔧 Correccions

  • El paquet de l'aplicació per a macOS queda completament segellat i el sistema ja no l'identifica com a malmès.
  • Els instal·ladors d'escriptori ara inclouen i carreguen la interfície completa de Gnosi.

Gnosi v1.0.0-rc.1

Prerelease
3 d'agost del 2026
Binaris disponibles a GitHub Releases: macOS (Apple Silicon) .dmg macOS (Intel) .dmg Windows .exe Linux .AppImage Linux .deb

✨ Destacats

  • La configuració s'organitza en seccions i pestanyes més clares.
  • Un nou portal de documentació d'enginyeria facilita entendre i mantenir el sistema.

🚀 Millores

  • El graf de coneixement té arestes més clares, millor informació de càrrega i relacions enfocades en passar-hi el cursor.
  • La navegació del coneixement i els controls de pàgina són més coherents i fàcils d'identificar.

🔧 Correccions

  • S'han corregit diverses inconsistències visuals de la configuració.
  • Els estats expandits i seleccionats de la interfície es conserven amb més fiabilitat.
