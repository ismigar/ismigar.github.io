Le problème que Gnosi résout

Votre recherche est un flux, pas une pile d’applications.

Des références dans un outil, des vues de projet dans un autre, des notes ailleurs et le texte final dans un quatrième éditeur. Le problème n’est pas de capturer plus de données, mais de conserver le chemin qui relie chaque affirmation à ses preuves.

↔

Travail en double

La même source et les mêmes métadonnées copiées entre votre gestionnaire bibliographique, vos notes de lecture et votre projet.

⌁

Preuves sans contexte

Les surlignages et les idées se détachent de la page, du paragraphe ou du texte original qui les étaye.

□

Connaissances sur terrain emprunté

Une hausse de prix ou un changement de politique peut enfermer des années de recherche structurée derrière les règles d’un fournisseur.

La réponse de Gnosi

Une chaîne de responsabilité ouverte pour vos connaissances.

Sources, preuves, notes, liens, vues de projet et citations restent connectés, tandis que les fichiers restent lisibles partout.

Parcours principal

Un cycle de recherche complet en quatre étapes

Commencez par votre propre matériel. L’IA peut aider, mais le flux n’en dépend jamais.

01

Capturer ou importer

Ajoutez des sources via DOI, ISBN, arXiv, PMID, BibTeX ou RIS. Enregistrez des pages web et ouvrez des PDF ou EPUB dans votre espace de travail.

Import compatible Zotero · Web Clipper
02

Lire avec les preuves

Annotez vos sources en conservant les citations liées à la page, au paragraphe, au chapitre ou à l’horodatage afin que les affirmations restent vérifiables.

Lecteur PDF/EPUB · Traçabilité
03

Relier et structurer

Transformez vos notes de lecture en synthèse. Utilisez les wikiliens, le graphe de connaissances, les bases de données, les tableaux, les frises et les jalons.

Markdown · Graphe · Vues de base de données
04

Écrire et citer

Insérez des citations Gnosi dynamiques dans Word ou LibreOffice et générez des bibliographies sans dupliquer vos bibliothèques.

CSL/citeproc · Word · LibreOffice
Conçu pour le travail réel

La structure de Notion, les connexions d’Obsidian et une couche de recherche native

A

Les sources deviennent des preuves exploitables

La gestion des références, les lecteurs, les annotations, les notes de lecture atomiques et les surlignages précis partagent un même contexte.

B

Les notes peuvent aussi être des données

Les pages Markdown accueillent des champs typés, des relations, des formules, des agrégations et des vues en tableau, galerie, tableau Kanban, calendrier ou chronologie.

C

L’IA reste responsable

Utilisez des modèles locaux ou cloud pour ingérer et interroger vos documents, tout en gardant la provenance claire et la synthèse sous contrôle humain.

Souveraineté dès la conception

Votre espace de travail doit survivre à l’application.

Gnosi utilise des fichiers standards comme source de vérité et des index reconstruisibles pour gagner en vitesse. Inspectez, copiez, versionnez et migrez vos connaissances quand vous le souhaitez.

Essayer Gnosi

L’application de bureau d’abord. Auto-hébergez-la quand vous en avez besoin.

Le chemin le plus rapide est la version de bureau. Les déploiements natif et Docker restent disponibles pour les utilisateurs techniques et les serveurs.

Recommandé
G

Application de bureau

Le backend est inclus. Le téléchargement détecte automatiquement votre système d’exploitation (Mac, Windows ou Linux).

Télécharger GnosiSur macOS : faites un clic droit → Ouvrir la première fois. Sur Linux : autorisez l’exécution (clic droit → Propriétés → Autoriser l’exécution comme programme) ou exécutez chmod +x fichier.AppImage.
Pour le développement

Exécution native

Exécutez Python et Node directement sur l’hôte. Recommandé pour l’auto-hébergement et les contributions.

git clone git@github.com:ismigar/Gnosi.git
cd Gnosi/apps/gnosi
Voir le guide d’installation native →
Pour les serveurs

Déploiement avec Docker

Utilisez le déploiement tout-en-un compatible lorsque l’installation en conteneur convient mieux au serveur.

docker compose up -d --build
Voir le guide Docker →
Un outil personnel, partagé ouvertement

Gnosi a été conçu pour un véritable flux de recherche.

Le projet est né pour éviter de dupliquer les connaissances entre Notion, Obsidian et Mendeley tout en conservant les avantages de chacun. Il est partagé avec la communauté comme logiciel libre, sans prétendre être une entreprise achevée ni une solution universelle.
