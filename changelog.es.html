Gnosi v1.0.0-rc.2

Prerelease
3 de agosto de 2026
Binarios disponibles en GitHub Releases: macOS (Apple Silicon) .dmg macOS (Intel) .dmg Windows .exe Linux .AppImage Linux .deb

✨ Destacados

  • Las aplicaciones de escritorio ahora utilizan el icono oficial de Gnosi en macOS, Windows y Linux.

🚀 Mejoras

  • Las compilaciones de release verifican la firma de macOS, el icono de la aplicación y la interfaz empaquetada antes de subir los instaladores.

🔧 Correcciones

  • El paquete de la aplicación para macOS queda completamente sellado y el sistema ya no lo identifica como dañado.
  • Los instaladores de escritorio ahora incluyen y cargan la interfaz completa de Gnosi.

Gnosi v1.0.0-rc.1

Prerelease
3 de agosto de 2026
Binarios disponibles en GitHub Releases: macOS (Apple Silicon) .dmg macOS (Intel) .dmg Windows .exe Linux .AppImage Linux .deb

✨ Destacados

  • La configuración se organiza en secciones y pestañas más claras.
  • Un nuevo portal de documentación de ingeniería facilita entender y mantener el sistema.

🚀 Mejoras

  • El grafo de conocimiento tiene aristas más claras, mejor información de carga y relaciones enfocadas al pasar el cursor.
  • La navegación del conocimiento y los controles de página son más coherentes y fáciles de identificar.

🔧 Correcciones

  • Se han corregido varias inconsistencias visuales de la configuración.
  • Los estados expandidos y seleccionados de la interfaz se conservan con más fiabilidad.
