Gnosi Privacy Policy

Last updated: July 27, 2026
Summary: The Gnosi application processes its working data locally on the user's device. The public landing website uses Google Analytics 4 with IP anonymization and Google Signals disabled to measure aggregate visits and link clicks.

Who we are

Gnosi is an open-source project maintained by Ismael Garcia Fernandez (ismigar@gmail.com). Optional paid deployment and support work may be offered separately; the application remains self-hostable.

What data Gnosi uses

With the user's explicit OAuth2 authorization, Gnosi may access the following data from the user's Google accounts:

  • Gmail (scope https://mail.google.com/): to read, send, and organize the user's mail via IMAP+SMTP+XOAUTH2.
  • Calendar (scope calendar): to read and synchronize calendar events.
  • Contacts (scope contacts): to read contacts and enrich references in messages and events.
  • OpenID + email: to identify the connected account.

Where data is stored

All data obtained via OAuth2 is stored exclusively on the user's local device (filesystem, local Vault). Gnosi never sells user data or uses the application's content for behavioural advertising.

OAuth2 tokens (access_token and refresh_token) are stored in the integrations.json file protected by the user's filesystem permissions.

How to delete your data

The user can revoke access at any time from Google Account permissions. The user can also delete the local Vault files and configuration.

Website analytics

The public website loads Google Analytics 4 to measure page views and clicks on outbound links such as downloads, GitHub Sponsors and Ko-fi. The configuration uses IP anonymization and disables Google Signals. This measurement is limited to understanding reach and conversion paths; it is not used to sell personal data or serve advertising.

Google may process this information under its own terms. You can block analytics with your browser privacy settings or a content blocker. The application itself does not load website analytics.

Changes to this policy

If the policy changes, the updated version will appear at this same URL with the new date. The latest version is always authoritative.

Contact

For any privacy-related questions or requests, please email ismigar@gmail.com.
