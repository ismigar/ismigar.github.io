Conocimiento

Editor de bloques

Editor WYSIWYG estilo Notion sobre Markdown: comandos slash, columnas, callouts y bloques embed (PDF, vídeo, web).

Bases de datos y vistas

Campos tipados (estado, relación, fecha, imagen, autoría...) y vistas tabla, galería, kanban, calendario y timeline.

Grafo de conocimiento

Visualiza wikilinks y etiquetas como un mapa interactivo (Sigma.js), con conexiones semánticas asistidas por IA.

Markdown portable

Ficheros Markdown que puedes leer y versionar con cualquier herramienta. Papelera con soft-delete. Cero lock-in.

Investigación académica

Gestor de referencias

Motor de citas compatible con Zotero (CSL/citeproc), importación por DOI/ISBN/arXiv/PMID y bibliografías APA.

Lector PDF/EPUB

Visor integrado (motor de Zotero); tus subrayados y anotaciones se convierten en citas reutilizables.

Lector RSS

Suscripciones RSS/POP3 con OPML jerárquico, extracción full-text, favicons y diseño limpio a tres columnas.

Convierte documentos en notas

El "Cerebro" transforma un PDF, EPUB o enlace en notas estructuradas con citas textuales y número de página, y el agente responde preguntas sobre tus documentos con fuentes verificables. Local-first con Ollama, o tu proveedor.

Add-in Word y LibreOffice

Inserta y gestiona citas desde Microsoft Word (Office Add-in) y LibreOffice Writer con la extensión «Gnosi Cite».

Contactos

Self-host (nativo)

Recomendado

Gnosi es un backend FastAPI + un frontend Vite. Se ejecutan directamente, sin contenedores.

# 1 · Backend (FastAPI) $ git clone https://github.com/ismigar/Gnosi.git $ cd Gnosi/apps/gnosi $ python3 -m venv .venv && source .venv/bin/activate $ pip install -r requirements.txt $ uvicorn backend.server:app --port 5002 --reload # 2 · Frontend (en otra terminal) $ cd Gnosi/apps/gnosi/frontend && npm install && npm run dev # 3 · Abre la app → http://localhost:5173

Opcional: Ollama para IA local. Guía completa en el README.

🐳

Docker

Opcional

¿Prefieres un solo comando o desplegar en un servidor? Docker agrupa backend, frontend y el translation-server de Zotero.

$ cd Gnosi/apps/gnosi $ docker compose up -d --build → http://localhost:5173

Alternativa todo-en-uno. No es necesaria para usar Gnosi.

Lleva Gnosi a Word, LibreOffice y tu navegador

Word (Gnosi Cite)

Disponible · beta

Office Add-in que inserta y gestiona citas de tu vault de Gnosi en Microsoft Word, estilo Mendeley Cite. APA 7, Chicago, MLA, IEEE.

  • Descarga el manifiesto y cárgalo en Word (sideload)
  • Ábrelo desde Inicio → Complementos → Complementos de desarrollador; entonces aparece el botón Cites Gnosi en la pestaña Referencias
  • En macOS, ejecuta una vez el instalador (con Word cerrado) y el panel se abre solo en los documentos nuevos; sin él, Word olvida los complementos cargados manualmente en cada sesión. En Windows el botón se mantiene solo.
  • Requiere Gnosi accesible por HTTPS (localhost por defecto)
  • Pega tu token de API (Configuración → API y tokens)
  • Word 2019+ en Windows, Mac y la Web

Para cualquier despliegue distinto de localhost, sustituye antes la URL del manifiesto. Descargar manifiesto · Notas de la versión · README.

LibreOffice

Disponible · beta

Extensión para Writer (.oxt) que inserta citas y genera bibliografías automáticas desde tu vault de Gnosi. Mismos estilos CSL y pipeline pandoc que el add-in de Word.

  • Descarga el .oxt y añádelo desde Herramientas → Extensiones
  • Reinicia LibreOffice
  • Gnosi Cite → Configuración → indica la URL del backend
  • Actualizar todo (APA) reformatea todas las citas de una vez, para que la desambiguación autor/año y los «et al.» queden correctos en todo el documento
  • LibreOffice 5.0+ (macOS, Windows, Linux)

Funciona con documentos .odt y .docx. Descargar .oxt · Notas de la versión · README.

🌐

Web Clipper

Disponible · beta

Extensión de navegador (Chrome/Edge/Brave, Manifest V3) para guardar páginas web —o solo la selección de texto— directamente en tu vault de Gnosi como notas.

  • Crea un token de API en Gnosi (Configuración → API y tokens)
  • Descarga y descomprime la extensión
  • Cárgala sin empaquetar en chrome://extensions (modo desarrollador)
  • Popup → pon tu URL de Gnosi y pega el token

Las páginas guardadas van a la carpeta Clips/ del vault. Descargar .zip · Notas de la versión · README.

Sostenibilidad y comunidad

Ayuda a mantener Gnosi independiente y libre

Gnosi es un proyecto de código abierto y sin ánimo de lucro. No hay recopilación de datos, ni publicidad, ni licencias de pago. Todo el software es soberano y está diseñado para ejecutarse localmente sobre tus propios archivos.

Sin embargo, el desarrollo continuo de Gnosi y el mantenimiento de la web conllevan costes reales en APIs de IA que asumo personalmente. Si valoras la herramienta, te invitamos a colaborar en su desarrollo o a ayudar económicamente a través de estas vías:
