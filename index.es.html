El problema que resuelve Gnosi

Tu investigación es un flujo, no una pila de aplicaciones.

Referencias en una herramienta, tablas de proyecto en otra, notas en otro lugar y el texto final en una cuarta aplicación. La fricción no consiste en capturar más información, sino en preservar el camino que lleva desde cada afirmación hasta la evidencia.

↔

Trabajo duplicado

El mismo recurso y los mismos metadatos copiados entre el gestor bibliográfico, las notas y el proyecto.

⌁

Evidencias sin contexto

Los subrayados y las ideas acaban desligados de la página, el párrafo o la fuente que los sustenta.

□

Conocimiento en terreno prestado

Un cambio de precios o políticas puede dejar años de trabajo estructurado bajo las reglas de otra empresa.

La respuesta de Gnosi

Una única cadena de custodia abierta para el conocimiento.

Fuentes, evidencias, notas, enlaces, vistas de proyecto y citas se mantienen conectados, mientras que los archivos siguen siendo legibles fuera de Gnosi.

El recorrido principal

Un ciclo de investigación completo en cuatro pasos

Empieza con tu propio material. La IA puede ayudar, pero el flujo no depende de ella.

01

Captura o importa

Añade referencias mediante DOI, ISBN, arXiv, PMID, BibTeX o RIS. Guarda páginas web y abre PDF o EPUB dentro del espacio.

Captura compatible con Zotero · Web Clipper
02

Lee con evidencias

Anota una fuente y conserva las citas vinculadas a la página, el párrafo, el capítulo o el minuto para poder comprobar cada afirmación.

Lector PDF/EPUB · Procedencia
03

Conecta y estructura

Convierte las notas de lectura en tu propia síntesis. Utiliza wikienlaces, el grafo, bases de datos, tableros, cronologías e hitos.

Markdown · Grafo · Vistas de base de datos
04

Escribe y cita

Inserta citas activas de Gnosi en Word o LibreOffice y genera la bibliografía sin duplicar la biblioteca.

CSL/citeproc · Word · LibreOffice

A

Las fuentes se convierten en evidencias útiles

Gestión de referencias, lectores, anotaciones, notas de lectura atómicas y resaltado exacto comparten el mismo contexto.

B

Las notas también pueden ser datos

Las páginas Markdown incorporan campos tipados, relaciones, fórmulas, agregaciones y vistas de tabla, galería, tablero, calendario o cronología.

C

La IA debe seguir rindiendo cuentas

Soberanía desde el diseño

Tu espacio debe sobrevivir a la aplicación.

Gnosi utiliza archivos normales como fuente de verdad e índices reconstruibles para ganar velocidad. Puedes inspeccionar, copiar, versionar y migrar el conocimiento sin pedir permiso.

  • Markdown + YAMLLegibles con un editor de texto y compatibles con herramientas de archivos ordinarias.
  • Local-firstEl uso personal no requiere una cuenta en la nube de Gnosi.
  • AGPL-3.0La aplicación es software libre y su desarrollo es público.
Prueba Gnosi

Primero la aplicación de escritorio. Alójala tú cuando lo necesites.

El camino más rápido es la versión de escritorio. Los despliegues nativo y Docker siguen disponibles para usuarios técnicos y servidores.

Aplicación de escritorio

El backend ya viene incluido. La descarga detectará automáticamente tu sistema operativo (Mac, Windows o Linux).

Descargar GnosiEn macOS: haz clic derecho → Abrir la primera vez. En Linux: activa "Permitir ejecutar como programa" en Propiedades o ejecuta chmod +x archivo.AppImage.
Para desarrollo

Ejecución nativa

Utiliza Python y Node directamente en el anfitrión. Es el flujo recomendado para el autoalojamiento y las contribuciones.

git clone git@github.com:ismigar/Gnosi.git
cd Gnosi/apps/gnosi
Consulta la guía de instalación nativa →
Para servidores

Despliegue con Docker

Utiliza el despliegue todo-en-uno compatible cuando una instalación en contenedores encaje mejor en el servidor.

docker compose up -d --build
